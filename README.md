# PEPG 3 Prototype

Current browser prototype extending the PEPG Board with modular governance concepts.

Modules represented in the current prototype:

- Board
- Context / Ontology
- Discuss
- Vote
- Rating
- Trust
- Delegate
- Verify
- Oversight

The current prototype remains browser-only and stores test interactions in memory.
