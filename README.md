# PEPG — Platform-Enabled People Governance

## Concept Prototype v0.6

This prototype is intentionally simple. Its purpose is to help people understand the PEPG concept before the community develops more advanced tools.

## Problem Detector

The home page contains a **Problem Detector**. A user can describe a public problem and prepare it for registration.

In this prototype, submissions are only simulated in the browser. A future version could store verified problems in a database.

## Problem-Centered Model

PEPG treats the **problem as the center of coordination**.

Example flow:

**Problem Identification → Solutions → Funding → Implementation → Contracts → Oversight → Reports**

The PEPG registry does not have to host every activity itself. Instead, each problem can point to appropriate external participation spaces.

## Public and private groups

The prototype uses two broad participation categories:

### Public spaces
Public groups are appropriate for:
- Problem identification
- Public discussion
- Solution proposals
- General funding discussion
- Public reports

These can be links to groups or communities on any social network, messaging platform, forum or website.

### Private / controlled spaces
Some functions can require controlled access:
- Implementation groups
- Formal oversight groups

For example, an implementation group may be limited to selected contractors and authorized project participants. An oversight group may require approval by the relevant public authority or another defined authorization process.

**Important:** These links are fictional example links. They do not point to real groups.

## Example Problem: Poor Asphalt Quality on an Abstract Street in Tanzania

PEPG-0002 demonstrates how one real-world-style problem could have several connected spaces:

- Problem Identification — public
- Solutions — public
- Funding — public
- Implementation — private / controlled
- Contracts — public
- Oversight — private / approved
- Reports — public

The important idea is that PEPG is **not dependent on a specific platform**. A public solutions group could exist on Telegram, WhatsApp, Facebook, a forum, or another service. PEPG only records and organizes the connection to that space.

## Design principle

> One problem, many participants, connected paths.

The purpose of this prototype is to make the concept understandable first. Authentication, governance rules, databases, APIs, blockchain, verification, voting and other advanced functions can be developed later by the community.
